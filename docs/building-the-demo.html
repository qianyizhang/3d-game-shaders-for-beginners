3D Game Shaders For Beginners

Building The Demo

Before you can try out the demo program, you'll have to build the example code first.

Dependencies

Before you can compile the example code, you'll need to install Panda3D for your platform. Panda3D is available for Linux, Mac, and Windows.

Linux

Install the Panda3D 1.10.16 C++ SDK, GCC and the Python 3.12 development headers. The build script defaults to the SDK's Ubuntu 24.04 package layout. For a different layout, set P3D_INCLUDE_PATH, P3D_LIB_PATH and PYTHON_INCLUDE_PATH.

From the repository root:

./demonstration/build-for-linux.sh

For more help, see the Panda3D manual.

Mac

Install the Panda3D 1.10.16 SDK for Mac. In the installer, select Customize → C++ Header Files. This SDK ships Intel C++ libraries, so Apple Silicon Macs run the demo through Rosetta. Use Apple Clang from Xcode or the Xcode Command Line Tools.

From the repository root, compile and link the demo:

./demonstration/macos.sh build

Use the Mac launch command from the repository root.

Windows

Start by installing the Panda3D SDK for Windows.

Make sure to locate where the Panda3D headers and libraries are.

For the original Windows setup, clone the upstream repository:

git clone https://github.com/lettier/3d-game-shaders-for-beginners.git
cd 3d-game-shaders-for-beginners

For more help, see the Panda3D manual.
