Set up the local scene

From the checkout root, install Panda3D 1.10.16 in a Python 3.12 virtual environment and run python mill-shader-lab/tools/convert_mill.py. Then run npm ci and npm run dev in mill-shader-lab/, and open the local address.

The lab needs a browser with WebGL 2 enabled. Open the original tutorial above to read the source lessons.
